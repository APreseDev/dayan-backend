# بک‌اند و پنل مدیریت تاسیسات دایان

Node.js (≥ 22.9) + Express 5 + PostgreSQL. پنل ادمین در مسیر `/admin` و API عمومی در `/api`.

## نصب
1. PostgreSQL نصب کنید و یک دیتابیس بسازید.
2. `cp .env.example .env` و مقادیر (`DATABASE_URL`، `PORT` و ...) را پر کنید.
3. `npm install`
4. `npm run migrate` (ساخت جدول‌ها؛ چند بار اجرا کردنش بی‌خطر است)
5. `npm run create-admin` (ساخت کاربر مدیر)
6. `npm start` سپس `http://localhost:PORT/admin/`

## اطلاعات شرکت
مقادیر اولیه در `src/defaultSettings.js` است (شماره تلفن و ایمیل فعلی نمونه‌اند). بعد از راه‌اندازی از «تنظیمات» پنل هم قابل ویرایش است.

## تست
`npm test`. برای تست روی دیتابیس واقعی `TEST_DATABASE_URL` را تنظیم کنید (محتوای آن دیتابیس پاک می‌شود، فقط دیتابیس تست بدهید).

## استقرار روی هاست ایرانی با دامنه .ir
- سرور/VPS با Node 22+ و PostgreSQL؛ برنامه را با `pm2` یا systemd اجرا کنید.
- Nginx جلوی برنامه (reverse proxy) با SSL؛ `NODE_ENV=production` را تنظیم کنید تا کوکی `Secure` فعال شود.
- `client_max_body_size 6m;` برای آپلود تصویر.
- فرانت ساخته‌شده (`dist`) را با `FRONTEND_DIST` از همین سرور سرو کنید.
- پشتیبان‌گیری منظم از دیتابیس (`pg_dump`) و پوشه `uploads/`.

## درگاه پرداخت (بعداً)
سفارش‌ها فعلاً بدون پرداخت آنلاین ثبت می‌شوند (وضعیت `new`). برای افزودن درگاه: مسیر ایجاد پرداخت و callback را در `src/routes/public.js` اضافه و فیلد وضعیت پرداخت را به جدول `orders` اضافه کنید.

## امنیت
نشست مبتنی بر کوکی HttpOnly، هدر ضد CSRF، قیمت‌گذاری سمت سرور، محدودیت نرخ درخواست، بررسی محتوای واقعی تصاویر آپلودی.

## فرانت‌اند (پروژه‌ی جدا: dian-frontend)
- توسعه: بک‌اند را روی پورت ۳۰۰۰ اجرا کنید، در پوشه‌ی فرانت `npm install && npm run dev`؛ مسیرهای `/api` و `/uploads` به بک‌اند پروکسی می‌شوند.
- انتشار: `npm run build` در فرانت، سپس مسیر پوشه‌ی `dist` را در `.env` بک‌اند به‌صورت `FRONTEND_DIST=/مسیر/dist` بدهید تا همان سرور سایت و API را سرو کند.
- محصولات و دسته‌ها فقط از پنل ادمین اضافه می‌شوند؛ بخش «محصولات ویژه» صفحه‌ی اصلی محصولاتی را نشان می‌دهد که «ویژه» علامت خورده باشند.
